# 📊 Sales Performance Dashboard

An interactive Sales Performance Dashboard built using **Microsoft Power BI** to analyze sales performance, targets, employees, and department-wise results.

## 🎯 Project Objective

The objective of this project is to analyze sales data and create an interactive dashboard that helps understand:

- Overall sales performance
- Sales against targets
- Monthly sales trends
- Department-wise sales
- Employee count
- Achievement percentage

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📌 Dashboard Features

- Total Sales KPI
- Total Target KPI
- Sales Count
- Employee Count
- Sales Department Actual
- Achievement %
- Monthly Sales Performance
- Department-wise Sales
- Department-wise Employee Count
- Interactive Department Filters
- Reset View Button
